# Trail Race Planner (web)

https://hirinyo2019-glitch.github.io/trail-race-planner/

トレイルレースのコース GPX から、CP ごとの通過予定・ゴールタイム・関門までの余裕を予測するアプリのブラウザ版です。
計算はすべてブラウザの中（Pyodide）で行い、登録したレースや予測の履歴はそのブラウザにだけ保存されます。
気温は Open-Meteo から取得します（コースの緯度経度を送ります）。

A browser version of Trail Race Planner. Predictions run entirely in your browser (Pyodide);
your races and saved predictions stay in this browser. Temperatures come from Open-Meteo.

This folder is generated by `scripts/build_static_web.py` in the app's source repository — do not edit it by hand.
